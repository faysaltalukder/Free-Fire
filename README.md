# Free Fire — Browser Battle Royale Prototype

An original, lightweight browser-based top-down survival shooter prototype. This is an independent learning/game-development project and is not affiliated with Garena or the official Free Fire game. It uses original canvas-drawn visuals and no copied game assets.

## Play locally
Open `index.html` in a modern browser. No build tools, package install, backend, or external assets are required.

## Controls
- **Move:** W A S D or arrow keys
- **Aim:** Mouse
- **Shoot:** Left mouse button (hold)
- **Reload:** R
- **Mobile:** Left virtual stick to move; FIRE button to shoot and aim

## Prototype features
- Top-down arena with camera follow
- Enemy bots with simple pursuit and shooting behaviour
- Player health, ammunition, reload, and eliminations
- Pickups for ammunition and medkits
- A shrinking safe zone that damages players outside it
- Responsive desktop and touch controls

## Project structure
- `index.html` — game shell and HUD
- `styles.css` — responsive visual design
- `game.js` — canvas rendering, controls, AI, combat, pickups, and zone logic

## Roadmap
1. Tune movement, combat, and bot behaviour.
2. Add original character and environment art.
3. Add more maps, weapons, inventory, and settings.
4. Explore multiplayer architecture only after the single-player foundation is stable.

The current build is a 2D prototype, not a 3D or online multiplayer recreation.
